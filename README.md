# Expo Counter App

A simple React Native application built with Expo and TypeScript.

## Features

- Increment counter
- Decrement counter
- Reset counter
- Reusable Floating Action Button (FAB)
- TypeScript support
- Expo development environment

## Technologies

- React Native
- Expo
- TypeScript

## Installation

Clone the repository:

```bash
git clone https://github.com/your-user/expo-counter-app.git
```

Navigate to the project directory:

```bash
cd expo-counter-app
```

Install dependencies:

```bash
npm install
```

Start the project:

```bash
npx expo start
```

## Running on Android

Option 1:

- Install Expo Go on your Android device
- Scan the QR code generated by Expo

Option 2:

- Use Android Studio Emulator
- Press `a` in the Expo terminal
